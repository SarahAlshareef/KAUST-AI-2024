
# KAUST AI Program – Exam Projects

## Overview
This repository contains machine learning tasks completed under supervised exam conditions as part of the KAUST AI Program. The projects demonstrate applied understanding of supervised learning across regression, classification, and computer vision problems.

All tasks were implemented independently within time-constrained assessment settings.

---

## Repository Structure

### 1️⃣ Linear Regression
Implementation of a regression model to predict a continuous target variable using structured numerical features.  
Evaluation metrics used:
- Mean Squared Error (MSE)
- R² Score

Focus: foundational regression modeling and performance interpretation.

---

### 2️⃣ Binary Classification
Implementation of a Logistic Regression classifier for a binary prediction task using structured data.  
Evaluation metrics used:
- Accuracy
- Confusion Matrix
- Precision, Recall, F1-score

Focus: classification workflow and metric interpretation.

---

### 3️⃣ EMNIST Character Classification
Neural network-based image classifier trained on the EMNIST handwritten character dataset.  
Focus areas:
- Image normalization
- Neural network training
- Multi-class classification accuracy evaluation

---
