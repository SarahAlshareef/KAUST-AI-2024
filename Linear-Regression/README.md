# Task 1 – Linear Regression

## Overview
This task implements a Linear Regression model to predict a continuous target variable using structured numerical features. The goal was to understand the fundamentals of regression modeling and evaluation.

## Problem Statement
Given a dataset with numerical features, the objective is to predict a continuous outcome variable using supervised learning.

## Data Preparation
- Dataset loading and inspection
- Feature and target separation
- Train-test split to evaluate model performance

## Modeling Approach
The model implemented:

- Linear Regression (Ordinary Least Squares)

The objective of the model is to minimize the difference between predicted and actual values using squared error minimization.

## Evaluation Metrics
Model performance was evaluated using:

- Mean Squared Error (MSE)
- R² Score

MSE measures the average squared difference between predictions and true values, while R² indicates how much variance in the target variable is explained by the model.

## Key Learning Outcomes
- Understanding regression problem formulation
- Implementing Linear Regression using scikit-learn
- Evaluating regression models using appropriate metrics
- Interpreting model performance using MSE and R²
