# Task 2 – Binary Classification

## Overview
This task focuses on implementing a binary classification model to predict one of two possible outcome classes using supervised learning techniques. The objective was to understand classification workflows, model training, and performance evaluation.

## Problem Statement
Given a structured dataset with numerical features, the goal is to classify each instance into one of two categories (0 or 1). This represents a supervised binary classification problem.

## Data Preparation
The following steps were performed:

- Dataset loading and inspection
- Feature and target separation
- Train-test split for proper model evaluation

These steps ensure the model is evaluated on unseen data to measure generalization performance.

## Modeling Approach
The classification model implemented:

- Logistic Regression

Logistic Regression models the probability of class membership using a sigmoid function and outputs binary predictions based on a decision threshold.

## Evaluation Metrics
Model performance was evaluated using:

- Accuracy Score
- Confusion Matrix
- Classification Report (Precision, Recall, F1-score)

The confusion matrix provides insight into true positives, true negatives, false positives, and false negatives, enabling deeper understanding of model behavior.

## Key Learning Outcomes
- Understanding binary classification problem formulation
- Training and evaluating a Logistic Regression classifier
- Interpreting confusion matrix results
- Using precision, recall, and F1-score to assess classification quality

## Conclusion
This task reinforced foundational concepts in supervised classification, including probability-based modeling, evaluation metrics, and performance interpretation.
